# CLAUDE.md

This file provides guidance to Claude Code when working in this repository.

## Coding Standards

All code written or modified in this project MUST strictly adhere to the requirements
defined in [`coding-standards.md`](./coding-standards.md). This is not optional guidance —
treat it as a hard constraint on every change.

If a task cannot be completed without violating a rule in `coding-standards.md`, or if
following `coding-standards.md` would conflict with another instruction, the current
codebase state, or otherwise create ambiguity about the correct approach — do NOT decide
unilaterally and do NOT silently deviate from the standard. Stop and ask the user how to
proceed before writing any code.
